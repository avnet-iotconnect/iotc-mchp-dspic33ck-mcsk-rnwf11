This dashboard works with anyone's /IOTCONNECT account - sign in with your own solution key, environment, email and password.

The solution key and your password are sent straight to this dashboard's own backend over HTTPS, never to a third party. Unlike the password (traded once for a session token), the solution key has to be resent with every request this page makes, so it stays in this browser tab's session storage - or, if you check the box above, in this browser's local storage - for as long as you're signed in. Use a private/incognito window if this is a shared computer.
